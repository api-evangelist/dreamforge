# DreamForge.ai

DreamForge.ai is an AI-powered platform for creating, iterating, and publishing 2D and stylized 3D games.
Users can generate gameplay systems, textures, game-ready assets, and playable web builds, then share public play pages.

## Public Game URLs
- Public games are available under: https://dreamforge.ai/play/{gameSlug}
- Only published games with live public versions and quality profile data are intended for indexing.


## 3D Notes
- DreamForge supports strong stylized 3D world generation, textures, voxels, and billboarding workflows.
- Native 3D model generation is not currently provided.
